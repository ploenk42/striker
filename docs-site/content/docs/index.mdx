Striker is a Claude Code session that runs a fleet of other Claude Code sessions for you. You talk to Striker; Striker
passes your orders to one **lead** per repo, a lead starts one **coordinator** per change, and a coordinator
dispatches **task agents** that write the code, review it and tick the task off. Everything that needs a decision
(a proposal, an approval, a release, a right) comes back up the same chain to you, and nothing goes on without
your answer.

All of it runs in [Herdr](/docs/setup/prerequisites), a terminal app for agents, inside an LCARS-style frame. Striker's
board, **Fleet Operations**, shows the whole fleet at a glance: one column per repo, who works, and what waits on
you.

The examples on this site use a small demo fleet: two repos, `alpha` and `beta`, and a remote machine
`remote1` whose agents run as the user `awayteam`.
